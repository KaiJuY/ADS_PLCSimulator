## 1. 目標

- **slot**：identity 檔中一個 `ServiceStatus.<path>`，例如 `Shutter.Open`。目前有 165 個 slot，其中 145 個 ServiceId 不是 0。
- **layout**：模擬器的 `PlcProgram` 依照宣告算出來的每個 symbol 的 offset 和 size（byte）。表格寫成 `offset / size`。
- **ServiceId**：每個 service 在 `ServiceStatus.<slot>.ServiceId` 回報的編號（UDINT）。0 表示這個 slot 沒有 service（例如 Arm3 沒有 NozzlePort）。
- **NaturalCompletion**：`E_ServiceCompletionBehavior` 的一個值。service 進入 Execute 後自己完成；另一個值 ExecuteUntilExternalStop 要等 client 下 Stop。
- **defaultDelayMs**：`Polar2_ServiceHost` workflow 的 `service.host` node 參數（5000）。沒有 duration 設定的 NaturalCompletion service 在 Execute 經過這段時間後 Complete（`ServiceHost.cs:441`）。單元測試用較短的值（`Polar2WorkflowTests.HostDocument`）。
- **ECID**：config parameter，放在 `ModuleConfigParamList`，內容由 `config/module-config.json` 在 Run 時寫入（`projects/Polar2Chamber/README.md:64`）。
- **真 PLC 854**：AMS Net ID 結尾 854 的實機 Polar2 PLC，`MaxConfigParamPerModule` 是 300（`projects/Polar2Chamber/README.md:3`）。
- **scientech-polar2-a9**：維護 `SRC_P2` 的另一個 Claude session，2026-11-02 做了這次的宣告比對。

- `MaxConfigParamPerModule` 維持 500：Allen 選擇和新版來源同步（issue）。450 和新版 Framework 相同，也放得下 438 筆 ECID，模擬器就不必另外修改 `Param_Config`。

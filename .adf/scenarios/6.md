## 過程中的發現

- 步驟 2 若 Run 後只等 3 s，S6、S7 失敗（服務狀態 Stopped／尚未就緒），三次重現；等 5 s 則 13/13。原因同 #3 記錄的「Host ready 後立刻跑 driver 時 S6、S7 失敗」：workflow 仍在啟動。舊流程在 HTTP 開始 listen 前就載入專案，所以「Now listening + 3 s」實際上更長。已更新 `.adf/profile.md` 的 Start 列：Run 後等約 5 s。不是本 issue 的退化。
- 第一次截圖時，disabled 的 Run／Stop 與一般按鈕外觀相同（DOM 已是 `disabled`）。`editor.css` 加 `.toolbar button:disabled, .toolbar select:disabled { opacity: 0.45; cursor: default; }`，步驟 6 截圖可見 Stop 淡化。
